## 📦 Lesson: Arrays in JavaScript

### 📝 Описание урока

Урок посвящен массивам в JavaScript — способам создания, базовым операциям добавления и удаления элементов, обращению по индексу, работе со свойством `length`, а также многомерным массивам.

### 📦 Изученные концепции

#### Создание массива

- **Конструктор** — через `new Array()`
  ```javascript
  const arr1 = new Array(); // конструктор массива
  ```
- **Литерал** — через `[]`
  ```javascript
  const arr2 = []; // литерал — предпочтительный способ
  ```

#### Добавление и удаление элементов

- **push() / pop()** — работа с концом массива
  ```javascript
  arr1.push('Яблоко', 'orange'); // добавить в конец
  arr1.pop(); // удалить последний элемент
  ```
- **unshift() / shift()** — работа с началом массива
  ```javascript
  arr1.unshift('delete elem 2'); // добавить в начало
  arr1.shift(); // удалить первый элемент
  ```

#### Обращение по индексу и length

```javascript
let fruits = ['Яблоко', 'Апельсин', 'Слива'];

console.log(fruits[0], fruits[1]); // обращение по индексу

fruits[2] = 'Ne fruct'; // изменение элемента по индексу

console.log('Длина \n', fruits.length); // количество элементов
```

#### Разные типы значений

Массив может хранить любые значения: функции, объекты, числа, глобальные методы — это просто упорядоченный список.

#### Многомерные массивы

```javascript
let matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9],
]; // массив массивов

console.log(matrix);
console.log(matrix.flat()); // выровнять до одномерного
```

Метод `flat()` «вскрывает» вложенные массивы и превращает их в плоский список.
