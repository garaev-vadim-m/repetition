## 🗺️ Lesson: Map and Set in JavaScript

### 📝 Описание урока

Урок посвящен коллекциям Map и Set в JavaScript, а также их «слабым» версиям WeakMap и WeakSet. Рассмотрены базовые методы, итерация, дедупликация данных и ограничения слабых коллекций.

### 📦 Изученные концепции

#### Map — коллекция «ключ: значение»

**Создание и основные методы**

```javascript
const map1 = new Map([['a', 'b']]); // можно с начальными парами
const map2 = new Map([['set', [{}]]]);

map1.get('a'); // получить значение по ключу
map2.has('set'); // проверить наличие ключа
map1.delete('1'); // удалить пару по ключу
map1.size; // количество элементов
map1.clear(); // очистить коллекцию
```

**Методы поддерживают цепочки вызовов и итерацию**

```javascript
map1.set('1', '2').set('2', '3').set('3', '4'); // цепочка set

console.log(map1.values()); // значения

for (const a of map1) {
  console.log(a); // итерация по парам
}
```

#### Set — коллекция уникальных значений

**Создание и добавление**

```javascript
let set1 = new Set();

set1
  .add(john)
  .add(john1)
  .add(john1) // дубликат — не добавится
  .add(pete);
```

Set автоматически отбрасывает дубликаты: повторное добавление того же значения игнорируется.

**Уникальные объекты**

```javascript
let uniq = [...set1]
  .map(({ id }) => id)
  .filter((value, index, values) => values.indexOf(value) === index)
  .map((value) => [...set1].find(({ id }) => id === value));

// Тот же результат короче через new Set
let uniq2 = [...new Set([...set1].map((value) => value.id))].map((value) =>
  [...set1].find(({ id }) => id === value),
);
```

Для получения уникальных объектов по полю нужно немного повозиться — можно отфильтровать по `id` вручную или собрать уникальные `id` через `new Set`.

#### WeakMap — слабая коллекция

- Ключами могут быть **только объекты** (не примитивы)
- Доступны только `get`, `set`, `delete`, `has`
- Значение «живёт», пока жив объект-ключ

```javascript
let weakMap = new WeakMap();
weakMap.set(john, 'data');
console.log(weakMap.get(john));

// weakMap.set("test", "Whoops"); // Ошибка: ключ — не объект
```

#### WeakSet — слабое множество

- Хранит **только объекты**
- Методы `add`, `has`, `delete`, но нет `size`, `keys()` и итерации

```javascript
let weakSet = new WeakSet();
weakSet.add([...set1]);
```

### 💡 Ключевые моменты

| Концепция        | Описание                                     | Пример                                  |
| ---------------- | -------------------------------------------- | --------------------------------------- |
| Map              | Пара ключ-значение, любые типы ключей        | `map.set(k, v)`, `map.get(k)`           |
| Set              | Уникальные значения, дубликаты отбрасываются | `set.add(v)`                            |
| Итерация         | `for...of`, `values()`, цепочки `set`        | `for (const a of map1)`                 |
| Уникальные объекты | Фильтрация по полю через `new Set`         | `[...new Set(ids)].map(...)`            |
| WeakMap / WeakSet | Ключи и значения — только объекты, без size  | `weakMap.set(obj, data)`                |

### 🎯 Когда использовать

- ✅ `Map` — нужна коллекция с произвольными ключами и встроенной итерацией
- ✅ `Set` — нужно хранить уникальные значения и быстро проверять наличие
- ✅ `WeakMap` / `WeakSet` — ассоциация данными с объектами без утечек памяти
- ❌ Не использовать `WeakMap` для использования в качестве ключа примитивных значений
