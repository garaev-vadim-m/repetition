## 🎭 Lesson: Decorators and Call/Apply

### 📝 Описание урока

Урок посвящен декораторам и переадресации вызова в JavaScript — методам `call` и `apply`, проблеме потери контекста `this` при передаче метода как колбэка, а также классическим паттернам декораторов.

### 📦 Изученные концепции

#### Проблема потери контекста `this`

Когда метод объекта передается как колбэк или сохраняется в переменную, он теряет свой контекст `this`:

```javascript
let user = {
  name: 'Vadim',
  sayHi() {
    console.log(this.name); // this — undefined вне объекта
  },
};

let fn = user.sayHi; // теряем контекст
fn(); // this === undefined
```

#### func.call(context, ...args)

`call` вызывает функцию, явно задавая `this` — первый аргумент, остальные передаются как обычные аргументы:

```javascript
func.call(context, arg1, arg2);
// this внутри func === context
```

#### func.apply(context, args)

`apply` делает то же, но внешне аргументы передаются массивом:

```javascript
func.apply(context, [arg1, arg2]);
```

#### Math.max через call/apply

Классический пример — передача массива в `Math.max`, который принимает отдельные числа:

```javascript
let arr = [3, 5, 1, 9, 2];

Math.max.apply(null, arr); // 9 — apply разворачивает массив
Math.max(...arr); // 9 — то же через spread
```

#### Переадресация вызова

Обёртка, которая полностью «переадресует» вызов исходной функции, сохраняя и `this`, и все аргументы:

```javascript
function wrapper() {
  return original.apply(this, arguments); // передаём this и все аргументы дальше
}
```

Благодаря `apply` обёртка не знает, сколько аргументов примет исходная функция.

#### Декоратор (например, кэширующий)

Декоратор — обёртка, которая добавляет функции новое поведение без изменения её кода:

```javascript
function cachingDecorator(func) {
  let cache = new Map();
  return function (x) {
    if (cache.has(x)) return cache.get(x); // берём из кэша
    let result = func.call(this, x); // вычисляем, сохраняя this
    cache.set(x, result);
    return result;
  };
}
```

### ✅ Результат

Понята проблема потери контекста `this`, освоены методы `call` и `apply` для явного задания контекста и передачи аргументов, а также паттерн декоратора для расширения поведения функций.

---

### 💡 Ключевые моменты

| Концепция                | Описание                                  | Пример                        |
| ------------------------ | ----------------------------------------- | ----------------------------- |
| Потеря `this`            | Метод, переданный как колбэк, теряет контекст | `let fn = user.sayHi`     |
| `call`                   | Вызов с явным `this` и поодиночными аргументами | `func.call(ctx, a, b)`  |
| `apply`                  | Вызов с явным `this` и массивом аргументов | `func.apply(ctx, [a, b])`     |
| Переадресация            | Обёртка сохраняет `this` и все аргументы  | `original.apply(this, arguments)` |
| Декоратор                | Обёртка, добавляющая поведение без правки исходной функции | `cachingDecorator(func)` |

### 🎯 Когда использовать

- ✅ Нужно вызвать функцию с конкретным `this`
- ✅ Передать массив туда, где ожидаются отдельные аргументы (`Math.max.apply`)
- ✅ Создать обёртку-декоратор, сохраняющую контекст и аргументы
- ✅ Добавить кэширование или логирование поверх существующей функции
- ❌ Для простого вызова с `this` из соседнего контекста проще использовать стрелочную функцию
